Bing Introduces Support for the data-nosnippet HTML Attribute

By Bing Search Team Jul 28, 2024 5 min read
The new data-nosnippet attribute gives publishers control over how search engines display snippets in search results and AI previews.
Search Privacy Snippet

With the data-nosnippet attribute, site owners can stop selected portions of a page from appearing in search snippets. This is useful for sensitive content, excerpts, or sections that should only appear on the page itself.

How to use data-nosnippet

Wrap the content you want to exclude using a supported HTML container like a paragraph or div. Bing will respect the mark-up when generating search previews.

<div data-nosnippet> This content will not be used for search snippets. </div>

Best practices

Use data-nosnippet sparingly. Keep the main page content visible to search engines so your page can still be understood and ranked correctly.

Monitor query performance after implementation, and adjust the sections that are hidden from snippets if visibility drops.
